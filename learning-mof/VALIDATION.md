# MOF 학습자료 검증

기초 중심 개편: 세 질문의 순서(정의·구성·결합), Zn₄O(COO)₆ 마디의 Zn₄C₆O₁₃ 구성, 수소를 켠 BDC의 C₈H₄O₄ 구성, 분자 확대·수소·연결 관계 전환과 유한한 3D 좌표를 검사했습니다. 새로운 Playwright 검사는 데스크톱·모바일에서 원자 모형·구성요소 확대·배위 결합 장면·드로 콜 수·가로 넘침·무 WebGL 대체 화면과 스크린샷을 검사하도록 추가했습니다. 실행 결과는 해당 브랜치의 GitHub Actions에서 확인합니다. 실제 CIF 구조나 사용자가 언급한 원본 3D 자료와의 동일성은 주장하지 않습니다.

내용을 쉽게 읽도록 개정했습니다. 핵심 한 문장과 짧은 이유를 먼저 표시하고, 기존 상세 이론·추가 변수·재생 설정을 접었습니다. 기본 화면의 불필요한 결과 카드와 중복 도입 그림을 줄였습니다. 접힌 조작을 펼친 후 값을 변경해도 선택·입력값과 패널 열림이 유지되는지 확인했습니다. 사진 원본은 현재 대화의 첨부와 작업 폴더에서 확인되지 않아, 사진과 일치 여부를 검증했다고 주장하지 않습니다.

설명 열의 빈 영역을 줄이기 위해 재생·장면 해설을 3D 옆 설명 열로 이동했습니다. 모든 장면에 짧은 인과 설명을 연결하고 도입부에는 기본 용어 설명을 배치했습니다. 모바일에서는 두 열 대신 문서 순서대로 그림과 설명을 읽도록 바꿨습니다. 장면을 바꾸면 관찰 내용과 이유가 함께 갱신되는지 DOM으로 확인했습니다. 실제 브라우저에서 보이는 여백·문자 배치는 아래 검증 한계와 같이 아직 확인하지 못했습니다.

2026-11-20 구현. 배포 대상 소스는 `main`의 `69d2c2c0a5147a26b70dd16846e856cca6249b52`를 기준으로 합니다. 기존 다른 기능의 미병합 작업은 포함하지 않습니다.

## 통과한 확인

- `node --check learning-mof/model.js`, `node --check learning-mof/app.js`.
- `NODE_PATH=/workspace/work/tooling/node_modules node tests/mof.test.cjs`: 모델·구조·DOM 통합 테스트.
- 길이비 1과 1.8의 부피비 1과 5.832, 중간값의 단조 증가. 선택 고리 수에 관계없이 고정된 금속 마디 반지름.
- 두 상호관입 연결망이 각각 연결되어 있으면서 서로 결합하지 않는 그래프 구조.
- 9단계의 모든 하위 장면에서 달라지는 그래픽 또는 구성요소 라벨. 모든 생성 좌표·Three.js 변환 행렬의 유한성.
- 활성화 전후 동일한 골격, 용매만 제거. 용매가 이동하며 빠지는 애니메이션.
- 정성 Langmuir 모형: 압력 0에서 점유율 0, 압력 증가·선택한 발열 모형의 온도 증가·친화력 차이·강체 입구 크기 제한.
- 320·390·800·1280 px의 컨테이너 폭을 주입한 DOM 환경에서 단계 선택, 고리 수, 구조 비교, 길이, 상호관입, 흡착 변수, 응용 선택, 장면 진행·재생·일시정지·초기화.
- 키보드 회전·확대, 포인터 회전, ARIA 단계 상태·출력, ID와 라벨 연결. 중복 초기화 시 리스너 중복 방지.
- 재생 종료·다시 재생·속도 변경. 동시에 예약된 애니메이션 프레임 최대 1개. 일시정지, 화면 밖, 숨긴 문서에서 프레임 예약 중지. 복귀 시 지나간 시간을 한꺼번에 진행하지 않음. 동작 줄이기 설정 변경 시 정지.
- 실제 Three.js 라이브러리의 장면·카메라·기하 계산 경로를 렌더러 스텁과 함께 실행. WebGL 생성 실패·컨텍스트 손실 시 SVG 입체 투영으로 전환.
- 기존 홈페이지의 두 상위 카드와 기존 학습 테마 경로 유지, MOF 진입 링크 추가. 로컬 스크립트·CSS 경로 유효.
- 비공개 미리보기는 동일 소스를 인라인해 로컬 경로 의존을 제거하고 Three.js MIT 라이선스를 포함.

## 학술 내용 확인

교수님 원본 자료는 첨부되지 않았으므로 제작 지시서와 저자 연구실 공개 논문 원문을 읽고 확인했습니다.

- Li 등, Nature 402 (1999), 276–279: MOF-5 구조, 겉보기 Langmuir 면적 약 2,900 m²/g, 큰 공동에서 단분자층 가정의 한계.
- Eddaoudi 등, Science 295 (2002), 469–472: BDC/BPDC/TPDC 계열, IRMOF-15/16의 상호관입 차이, 농도 조절에 따른 비상호관입 구조.
- 1.8³은 교육용 공간 부피비, 1.4는 중간 비교 가정으로 명시. 실제 기공 부피나 흡착량을 산출하지 않음.

## 검증 한계와 공개 전 확인

이 실행 환경에는 지원되는 브라우저 제어 도구가 없습니다. DOM 폭 주입 검사는 실제 CSS 레이아웃 검사와 다릅니다. **실제 데스크톱/모바일 브라우저의 가로 넘침, 터치 감각, 텍스트 배치, WebGL 래스터화와 화면 캡처는 검증하지 못했습니다.** 브라우저나 별도 서버를 임의로 설치·실행하지 않았습니다.

비공개 미리보기에서 다음을 확인한 뒤 GitHub Pages에 공개합니다.

1. 휴대전화 세로 화면에서 가로 스크롤과 라벨 겹침 여부.
2. 3D 구조 회전·확대, 고리 비교, 상호관입 ON/OFF, 흡착 장면의 화면 표시.
3. 기존 홈페이지에서 ALE 및 다른 학습자료가 열리는지 확인.

기존 학습자료 소스와 Three.js vendor 파일은 이번 변경 목록에 포함하지 않습니다. GitHub Pages 공개 배포는 미리보기 검토 이후 진행하는 검토용 변경입니다.
