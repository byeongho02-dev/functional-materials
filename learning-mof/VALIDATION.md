# MOF 학습자료 검증

2026-11-22 교육 보완. 기존 기초 3개 질문·심화 6개 주제와 분자 모형을 유지하고 이야기 연결, 비유의 한계, 변수 설명과 하단 참고문헌을 보완했습니다. 본문의 안내·출처 줄과 퀴즈·자기 설명 UI는 사용자 요청으로 제거했습니다. 이번 수정은 `codex/mof-foundations-3d`의 기존 검토본 위에 적용합니다. 다른 학습자료의 미병합 작업은 포함하지 않습니다.

## 로컬 검증

```sh
node --check learning-mof/model.js
node --check learning-mof/molecular.js
node --check learning-mof/learning.js
node --check learning-mof/app.js
node --check tests/pages/mof.spec.cjs
NODE_PATH=/workspace/work/tooling/node_modules node tests/mof.test.cjs
```

Node 모델·구조·DOM 통합 검사는 다음을 확인합니다. DOM 폭 주입은 실제 CSS 레이아웃 검사를 대체하지 않습니다.

- 기초 순서(정의·구성·결합), Zn₄O(COO)₆ 마디와 BDC(C₈H₄O₄)의 원자 구성, 확대·수소·연결 관계 전환.
- 모든 하위 장면에서 변화하는 그래픽과 유한한 좌표·변환 행렬, 실제 Three.js 수학·장면 경로(렌더러는 스텁).
- 길이비 1/1.8과 기하 공간 부피비 1/5.832, 길이만 바꾸어도 금속 노드 크기는 유지.
- 각각 연결되어 있으나 서로 결합하지 않은 두 상호관입 그래프.
- 활성화 중 골격은 유지하고 용매만 제거.
- 단일 기체 모형의 압력·온도·친화력·입구 제한, 압력 0에서 점유율과 표시 입자 0.
- 320·390·800·1280 px DOM 환경에서 9개 주제·조작·재생·초기화·ARIA·키보드·포인터 조작.
- 모든 주제에서 제거한 영역이 생성되지 않음과 하단 참고문헌 연결.
- 재생 종료, 동작 줄이기 변경, 화면 밖·숨긴 페이지에서 프레임 중지, 복귀 시 시간 건너뛰기 방지, 중복 리스너 방지.
- WebGL 생성 실패·컨텍스트 손실 시 SVG 대체, 로컬 스크립트·CSS 경로.

## 실제 브라우저·프로젝트 검사

이 관리 환경에는 지원되는 로컬 브라우저 제어 도구가 없어 기존 GitHub Actions의 Playwright를 사용합니다. 새 서버나 브라우저 의존성을 페이지에 추가하지 않습니다.

저장소의 `Validate isolated ICP preview`는 `npm ci` 뒤 기존 `test:fab`와 `test:pages`를 실행합니다. `test:pages`는 정적 미리보기 빌드, Node 회귀 검사, 실제 Chromium 검사를 포함합니다. 별도 린트 명령은 정의돼 있지 않습니다. `Validate static site`도 변경 경로와 정적 페이지를 검사합니다.

`tests/pages/mof.spec.cjs`의 확인 항목:

- 1440×1000, 390×844에서 WebGL·원자 모형·마디/링커 확대·수소·연결망 전환·배위 결합·재생.
- 본문 안내·출처 줄과 퀴즈·자기 설명 영역이 생성되지 않음.
- 링커 변경, 물리량 비교 표, 상호관입·안정성 안내, 압력·분자 크기·온도의 키보드 조작, 센서 선택.
- 기초로 돌아온 후 3D 확대 정상 동작, 320 px에서 모든 주제의 가로 넘침 검사.
- WebGL 없는 SVG 대체와 페이지 JavaScript 오류 검사.
- 전체 페이지 스크린샷: 기초·마디·링커·배위 결합·정리한 학습 화면·상호관입·흡착. 증거는 Actions의 `icp-preview-test-evidence` 아티팩트에 저장합니다.

최종 실행 상태와 커밋별 로그는 검토 PR의 Checks 및 작업 결과 보고에서 확인합니다. 과거 분자 확대 구현도 `f3c9e1d58819b4788a2137e3ac9b02d4342330bf`의 Actions 실행 `44703368930`에서 통과했습니다.

## 과학 내용과 검증 한계

Li(1999)·Eddaoudi(2002)의 저자 공개 원문을 대조했습니다. 추가 검토 논문의 DOI·서지 정보와 IUPAC 용어 보고서를 확인하고 관련 설명 옆에 연결했습니다. 새 성능 수치나 미확인 IRMOF 치수는 추가하지 않습니다. 문헌의 Langmuir 추정값, 교육용 거리비, 무차원 흡착 모형을 서로 구분합니다. 상세 범위와 일곱 학습 목표 대응은 [LEARNING-REVIEW.md](LEARNING-REVIEW.md)에 있습니다.

- 실제 CIF 기반 구조 해석, 전자 밀도·결합 에너지·반응 경로·분자 동역학을 검증한 계산은 아닙니다.
- 실제 흡착량·혼합 기체 선택도·산업 성능을 예측하지 않습니다.
- 비전공자 대상 사용성 실험이나 학습 효과 연구를 수행하지 않았습니다. 내용의 목표 대응과 기능 회귀를 검사한 것입니다.
- 실제 기기의 터치 감각, 모든 브라우저·스크린리더 조합은 별도 확인이 필요합니다.
- 제공된 원본 사진·결정 좌표와의 동일성을 주장하지 않습니다.

동일한 소스를 개인 미리보기에 인라인할 때는 로컬 Three.js의 MIT 라이선스를 포함하고, 외부 스크립트·CDN 없이 동작하도록 포장합니다.
