# MOF 교육 내용 점검

기존 코드를 읽고 보완한 범위입니다. 사용자에게 설명할 능력을 보장하는 실험 결과가 아니라, 페이지의 설명·그림이 목표와 연결되는지 확인한 내용 점검입니다. 실제 비전공자 대상 사용성·학습 효과 평가는 아직 하지 않았습니다.

## 기존 구조와 보완점

기초의 정의·구성·결합 세 질문, 심화 여섯 주제, 원자 모형·연결망 전환, 부품 확대, 구조·흡착 조작, SVG 대체 화면이 이미 있었습니다. 이를 유지하면서 다음을 보완했습니다.

- 각 장의 비유에 실제 현상과 다른 점을 붙이고, 정의를 3D보다 먼저 읽을 수 있도록 배치했습니다.
- 전문 용어의 첫 등장 설명과 관찰→원인→다음 질문의 연결을 정리했습니다.
- 학습 흐름을 간결하게 하기 위해 별도 안내·출처 줄과 퀴즈·자기 설명 영역을 제거했습니다. 참고문헌은 하단에서 펼쳐 읽습니다.
- 변수의 뜻·변화 원인·정량 해석의 한계를 조작 바로 옆에 표시했습니다.
- 흡착/흡수/확산, 네 가지 물리량, 안정성, 센서와 산업 적용의 제약을 보완했습니다.

이 표는 학습 목표에 대한 내부 내용 점검표입니다. 페이지에는 객관식 퀴즈나 자기 설명 입력란을 두지 않으며, 학습 성취도를 자동 평가하지 않습니다.

## 과학적 범위와 근거

- MOF-5 = IRMOF-1, Zn₄O(BDC)₃와 IRMOF-10/BPDC·IRMOF-16/TPDC의 대응은 Li(1999)·Eddaoudi(2002)의 사례를 사용합니다. IRMOF-15/16은 상호관입/비상호관입 구조 비교입니다.
- 원자 배치와 기공 윤곽은 교육용이며 실제 CIF 좌표·실측 기공 경계가 아닙니다. 여섯 연결 방향은 노드 전체의 연결도입니다.
- 거리비 1/1.4/1.8과 그 세제곱은 교육용 가정입니다. 실측 기공 직경·기공 부피·표면적·흡착량으로 환산하지 않습니다.
- 약 2,900 m²/g는 Li(1999)의 **겉보기 Langmuir** 추정값입니다. BET 값이나 모든 시료의 보장값이 아닙니다. 원문의 단분자층 가정 한계도 표시합니다.
- 단일 성분 Langmuir 식에 임의 무차원 계수를 사용합니다. 압력·온도·입구 크기에 따른 경향을 보여 줄 뿐 실제 흡착량·확산계수·혼합 기체 선택도를 예측하지 않습니다. 입자 이동은 개념 경로입니다.
- 물리량·흡착 용어는 IUPAC(2015), 안정성은 Burtch(2014)·Howarth(2016), 센서는 Kreno 등의 검토 논문을 출처로 연결했습니다. 추가한 산업 설명은 정성적 확인 항목이며 검증되지 않은 성능 수치는 넣지 않았습니다.
