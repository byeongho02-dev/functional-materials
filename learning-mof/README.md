# MOF 학습자료

`learning-mof/index.html`은 금속–유기 골격체의 구성, 배위 결합, 골격 형성, 망상 화학, 길이–부피 관계, 상호관입, 비표면적, 흡착, 활용을 9단계로 설명합니다. 기존 홈페이지의 **Materials Learning → MOF · 금속–유기 골격체**에서 진입합니다.

## 실행과 파일

GitHub Pages에서 빌드 없이 동작하는 HTML/CSS/JavaScript입니다. 외부 API·CDN·실행 의존성은 추가하지 않습니다.

- `index.html`: 페이지, 실험 컨테이너, 용어와 참고문헌
- `styles.css`: 기존 홈페이지에 맞춘 네이비·시안 디자인과 반응형 레이아웃
- `model.js`: 독립적인 교육 모형, 9단계 한국어 설명, 구조 그래프와 그래픽 데이터
- `app.js`: Three.js/SVG 렌더링, 조작, 애니메이션 수명 관리
- `../tests/mof.test.cjs`: 수식·구조·DOM 통합 검증
- `VALIDATION.md`: 수행한 검증과 수행하지 못한 검증

Three.js는 저장소에 이미 있는 `../learning-electromagnetic/vendor/three.min.js`를 그대로 사용합니다. 기존 전자기 학습 페이지와 다른 학습자료의 소스는 수정하지 않습니다. WebGL을 사용할 수 없거나 컨텍스트를 잃으면 동일한 구조 데이터를 이용하는 회전 가능한 SVG 입체 투영 모식도로 전환합니다.

## 조작법

첫 화면은 핵심 한 문장·쉬운 원인 설명·관찰할 행동을 먼저 보여 줍니다. 전문 용어와 원래의 전체 설명은 **용어·이론 더 보기**, 회전 버튼·진행률·속도·처음부터는 **보기·재생 설정**에서 펼칩니다. 흡착의 기본 조작은 압력 하나로 시작하며, 온도·분자 크기·가상 기체 비교는 **온도·분자 크기도 바꿔 보기** 안에 있습니다. 접힌 상태에서도 기하 모형과 실험값의 차이를 짧게 표시합니다. 9개 주제와 기존 구조 모형·계산은 유지합니다.

넓은 화면에서는 3D 옆에 핵심 설명·장면 해설·실험 조작이 한 열로 이어집니다. 3D 아래에 있던 재생 영역을 설명 열로 옮겨 긴 빈 영역을 줄였으며, 각 장면에 **그림에서 볼 것 / 왜 그럴까요?**를 함께 표시합니다. 3D는 설명을 읽는 동안 화면에 머물고, 모바일에서는 그림 다음에 설명이 자연스럽게 이어집니다. 도입부의 여유 공간에는 마디·링커·기공의 짧은 뜻을 배치했습니다.

1. 9개 학습 단계 중 하나를 선택합니다. 모든 단계에 핵심 한 문장, 장면별 이유, 접을 수 있는 자세한 원리가 있습니다.
2. 재생/일시정지, 이전/다음 장면, 진행 슬라이더, 0.5–2배 속도, 처음부터를 사용합니다. 마지막 장면에서 재생이 끝납니다. 처음부터는 현재 단계의 변수와 시점을 초기화합니다.
3. 구조는 드래그, 휠, 회전·확대·축소 버튼으로 조작합니다. 구조 영역에 키보드 초점을 놓으면 방향키로 회전, `+`/`-`로 확대·축소, `Home`으로 시점 초기화, `Space`로 재생/일시정지합니다. 터치 스크롤과 대체 버튼을 함께 제공합니다.
4. 4단계: 고리 1·2·3개와 같은 배율 비교. 5단계: 상대 길이. 6단계: 상호관입 ON/OFF. 7단계: 내부 표면 강조. 8단계: 상대 압력·온도·크기와 가상 기체 A/B. 9단계: 활용 분야를 선택합니다.

자동으로 재생을 시작하지 않습니다. `prefers-reduced-motion`을 따르며 동작 줄이기 설정이 켜지면 재생을 멈춥니다. 사용자가 재생을 선택한 경우에만 움직입니다. 화면 밖·숨긴 페이지에서는 프레임 예약을 취소하고 복귀 시 지난 시간을 건너뛰지 않습니다. 렌더링은 최대 약 30fps, 픽셀 비율은 최대 1.5입니다. 공유 지오메트리와 재질을 재사용하고 비활성 메시를 제거합니다. 중복 실행 시 이벤트를 다시 연결하지 않습니다.

## 학술적 범위

- **교육용 모식도**: 실제 CIF 좌표, 전자 궤적, 합성 중간체, 반응 속도를 재현하지 않습니다. 입방형 연결망의 파란 구는 Zn₄O 기반 SBU 전체입니다. Zn₄O 클러스터를 벌크 ZnO와 구분합니다. 여섯 방향은 마디 전체 연결도이며 단일 Zn의 배위수가 아닙니다.
- 배위 결합의 전자쌍은 리간드가 제공해 공유되는 것으로 설명합니다. 완전한 전자 이동이나 금속 환원으로 설명하지 않습니다. BDC²⁻와 산 형태 H₂BDC를 구분합니다.
- **활성화**는 기존 기공의 용매 제거입니다. 골격에 사후 가공으로 기공을 만드는 장면이 아닙니다. 6장면은 구조 학습 순서이며 실제 합성 순서가 아닙니다.
- **거리와 부피**: 고리 1/2/3의 상대 마디 거리 1/1.4/1.8 중 1.8은 제작 지시서의 가정, 1.4는 중간 비교값입니다. `1.8³ = 5.832`는 골격 원자의 배제 부피를 빼지 않은 기하학적 비교입니다. 격자 상수·마디 거리·기공 직경·기공 부피·접근 가능한 공간을 구분합니다. 실제 기공 부피나 흡착량의 6배 증가를 주장하지 않습니다.
- **상호관입**: 두 그래프는 각각 연결되어 있으나 그 사이 결합은 없습니다. IRMOF-15/16은 TPDC 기반 상호관입/비상호관입 비교 사례입니다. 긴 링커가 상호관입을 보장하지 않으며, 성능 변화는 응용·합성 조건에 따라 다릅니다. 애니메이션은 완성된 결정에 다른 골격을 끼우는 실제 공정이 아닙니다.
- **비표면적**: Li 등(1999)이 보고한 겉보기 Langmuir 약 2,900 m²/g를 사용합니다. 원문은 큰 공동에서 단분자층 가정이 엄밀하지 않을 수 있음을 명시합니다. BET 값과 동일시하지 않습니다. `2,900 / (28 × 15) ≈ 6.90`은 1 g에 대한 농구장 면적 비유입니다. 시료·합성·활성화·측정법에 따라 달라질 수 있습니다.
- **흡착 모형**: 단일 성분 Langmuir `θ=bP/(1+bP)`, 임의 무차원 `b=b₀ exp[1.6(1/Tᵣ−1)]`를 사용합니다. 가상 A/B의 `b₀`는 2와 0.5이며 실험 피팅값이 아닙니다. 이 발열성 물리흡착 예시에서만 높은 온도는 점유율을 줄입니다. 크기비 1 초과는 강체 입구 근사로 차단합니다. 실제 유연성·확산·혼합 기체 경쟁·미세기공 충전은 계산하지 않습니다. 입자 수는 개념 표현이며 실험 흡착량이나 혼합물 선택도가 아닙니다.
- 촉매와 CO₂ 포집은 적합한 활성점·표면 화학을 설계한 MOF의 일반적 응용입니다. MOF-5가 모든 응용에 적합하다는 의미가 아닙니다.

교수님 원본 슬라이드·그림은 현재 첨부에서 확인되지 않아 제작 지시서와 다음 두 논문의 원문을 기준으로 구성했습니다. 논문 그림을 복사하지 않고 모식도를 새로 그렸습니다.

## 참고문헌

1. Li, H. et al. Nature 402, 276–279 (1999). [DOI](https://doi.org/10.1038/46248), [저자 공개 원문](https://yaghi.berkeley.edu/pdfPublications/nature99-pg276.pdf). MOF-5 구조, Langmuir 면적과 단분자층 가정의 한계를 확인했습니다.
2. Eddaoudi, M. et al. Science 295, 469–472 (2002). [DOI](https://doi.org/10.1126/science.1067208), [저자 공개 원문](https://yaghi.berkeley.edu/pdfPublications/469.pdf). 링커 계열, IRMOF-15/16과 농도에 따른 상호관입 차이를 확인했습니다.

## 검증 재실행

```sh
node --check learning-mof/model.js
node --check learning-mof/app.js
node tests/mof.test.cjs
```

기본 테스트는 Node 표준 라이브러리만 사용합니다. 선택적인 DOM 통합 검증에는 실행 환경에 별도 설치된 `linkedom`을 사용합니다. 사이트의 배포 의존성은 아닙니다. `NODE_PATH`로 외부 설치 위치를 지정하면 DOM 테스트도 수행합니다. Three.js의 수학·장면 경로는 실제 라이브러리와 렌더러 스텁으로 검사하며, 브라우저의 WebGL 렌더링을 대체하지 않습니다.
