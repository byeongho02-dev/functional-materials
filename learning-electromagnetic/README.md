# 전자기파와 기능성 재료

Materials Learning의 **나노전자재료 및 전자파 차폐** 테마에서 여는 학습자료입니다.

- `index.html`: 한국어 설명, 슬라이더, 3개 학습 탭과 확인 문제
- `styles.css`: 다크 테마와 모바일 레이아웃
- `app.js`: 탭, 학습용 계산, Three.js 장면
- `vendor/three.min.js`: Three.js 0.160.1, MIT 라이선스는 `vendor/THREE-LICENSE.txt`

별도 빌드나 CDN 없이 GitHub Pages에서 실행합니다. 홈페이지의 ALE 시뮬레이터와 기존 학습자료는 각각의 경로를 유지합니다.

## 모델 범위

차폐는 지정한 반사율과 표피 깊이에 따른 단일 통과 근사입니다. 초전도체는 92 K를 경계로 한 이상화된 상태와 저항을 표현하며 자기장·힘·이력을 계산하지 않습니다. 메타표면은 정면 입사와 같은 매질에서 이상적 위상 구배에 따른 조향각을 계산합니다. 실제 측정값이나 설계 예측값이 아닙니다. 각 탭의 가정과 참고자료를 함께 읽어주세요.

## 수정 후 확인

미배포 검토본은 EMI·메타표면 3D 위에 관찰 과정 선택을 추가합니다. 입력은 유지하고 경로·재료 반응·전체 결과를 강조합니다. EMI 내부 파의 진폭은 기존 단일 통과 근사와 같은 exp(−x/δ)로 감쇠합니다. 청록 점은 전자의 진동 반응, 보라 점은 열 소산의 정성 기호이며 실제 미시 수송·궤적을 계산하지 않습니다.

메타표면 3D 바늘은 국소 전기장 위상입니다. 별도 접이식 실험은 동일 진폭 점파원 9개의 파를 관찰 방향에서 더합니다. 정규화 배열 인자는 실측 효율이 아니며 소자 응답·편광·흡수·반사·3D 전자기장 해석을 생략합니다. 기존 위상 구배가 지정하는 전파 해가 없어도 다른 방향의 파는 남을 수 있습니다. 학술 배경은 Yu 등(2011) 링크를 따릅니다.

새 `cooper-pair.js`·`cooper-pair.css`는 YBCO(92 K) 마이스너·자속 고정 3D와 독립적입니다. 전통적 포논 매개 BCS의 반발 → 격자 지연 → 유효 인력 → 넓은 쌍 상관 → 거시 위상 결맞음 → 갭·위상 강성 → 임계 조건 아래 지속 전류를 7단계 SVG로 설명합니다. YBCO의 쌍 형성 기작을 단정하지 않습니다. 단계·재생·진행·속도·위상 무질서·비틀기·갭 기준 비교·임계 조건을 조작하며 상세 이론은 접혀 있습니다. 무질서 상태에서는 매끄러운 비틀기 조작을 잠급니다. Westlake 참고 PDF는 HTTP 403으로 본문을 직접 검증하지 못했습니다.

3D에 방향키 회전, +/− 확대, Home 초기화, Space 재생을 추가했습니다. 숨김·화면 밖·일시정지의 렌더 부담을 줄이고 동작 줄이기 설정 변경을 반영합니다. 공개 페이지는 이 검토본을 반영하지 않았습니다.

```sh
node --check learning-electromagnetic/app.js
```

홈페이지 → Materials Learning → 나노전자재료 및 전자파 차폐 → 학습자료 진입, 세 탭의 슬라이더·기본값·확인 문제, 학습 테마로 돌아가기를 확인합니다. WebGL을 사용할 수 없는 경우 2D 대체 보기와 계산 기능을 사용합니다.
