# 전자기파와 기능성 재료

Materials Learning의 **나노전자재료 및 전자파 차폐** 테마에서 여는 학습자료입니다.

- `index.html`: 한국어 설명, 슬라이더, 3개 학습 탭과 확인 문제
- `styles.css`: 다크 테마와 모바일 레이아웃
- `app.js`: 탭, 학습용 계산, Three.js 장면
- `cooper-pair.js`: 독립된 7단계 Cooper Pair Lab, SVG 애니메이션과 정성적 비교
- `vendor/three.min.js`: Three.js 0.160.1, MIT 라이선스는 `vendor/THREE-LICENSE.txt`

별도 빌드나 CDN 없이 GitHub Pages에서 실행합니다. 홈페이지의 ALE 시뮬레이터와 기존 학습자료는 각각의 경로를 유지합니다.

## 모델 범위

차폐는 지정한 반사율과 표피 깊이에 따른 단일 통과 근사입니다. 초전도체는 92 K를 경계로 한 이상화된 상태와 저항을 표현하며 자기장·힘·이력을 계산하지 않습니다. 메타표면은 정면 입사와 같은 매질에서 이상적 위상 구배에 따른 조향각을 계산합니다. 실제 측정값이나 설계 예측값이 아닙니다. 각 탭의 가정과 참고자료를 함께 읽어주세요.

## 수정 후 확인

```sh
node --check learning-electromagnetic/app.js
node --check learning-electromagnetic/cooper-pair.js
node --test tests/cooper-pair.test.cjs
```

홈페이지 → Materials Learning → 나노전자재료 및 전자파 차폐 → 학습자료 진입, 세 탭의 슬라이더·기본값·확인 문제, 학습 테마로 돌아가기를 확인합니다. WebGL을 사용할 수 없는 경우 2D 대체 보기와 계산 기능을 사용합니다.

## Cooper Pair Lab

초전도체 탭의 기존 3D 실험 아래에서 엽니다. 새 모듈은 SVG와 정적 JavaScript만 사용하며 빌드, CDN, 외부 API, 추가 실행 의존성이 필요하지 않습니다.

1. 직접 쿨롱 반발: 서로 멀어지는 두 전자와 반발 방향
2. 격자 지연: 전자가 지나간 뒤 시작되는 이온 변위와 잔류 진동
3. 포논 매개 성분: 직접 반발을 유지한 채 격자 매개 유효 인력의 경로 비교
4. 쿠퍼쌍: (k, ↑), (−k, ↓)와 넓게 겹치는 상관 상태의 구름
5. 거시적 결맞음: 공간 영역의 질서변수 위상 관계, 무질서 및 매끄러운 위상 기울기
6. 안정성: 준입자 에너지 갭과 위상 변형의 비용을 독립 비교
7. 지속 전류: 위상 질서와 임계 조건을 만족하거나 벗어나는 경우 비교

### 조작

- 단계 버튼 또는 이전/다음: 설명·범례·그래픽이 함께 바뀝니다. 단계 버튼에 초점을 둔 뒤 좌우 화살표, Home, End도 사용할 수 있습니다.
- 자동재생/일시정지: 현재 단계부터 진행하고 7단계 끝에서 정지합니다. 끝에서 다시 재생하면 1단계부터 시작합니다.
- 처음부터: 모든 새 실험 조작을 기본값으로 되돌립니다.
- 장면 진행 슬라이더: 움직임을 멈춘 채 임의 시점을 관찰합니다.
- 격자 반응 보기: 2단계를 한 번 재생한 뒤 그 단계에 머뭅니다.
- 속도: 0.5/1/1.5/2배, 실제 이온의 물리적 진동수와 관계없는 재생 속도입니다.
- 3단계: 격자 매개 경로 표시를 꺼도 직접 쿨롱 반발은 남습니다.
- 5·6단계: 결맞음/무질서와 이웃 영역의 위상 비틀기를 비교합니다. 매끄러운 기울기는 곧 위상 무질서라는 뜻이 아닙니다.
- 6단계: BCS 갭 표시를 끄면 갭 없는 분산과 비교합니다. 이 도해 선택은 다른 단계의 시료 상태를 계산하거나 바꾸는 물리 모델이 아닙니다.
- 7단계: 임계 조건 체크와 위상 질서를 바꿔 지속 전류의 조건을 비교합니다. 체크박스로 실제 임계장·임계전류를 예측하지 않습니다.

### 과학적 범위

기존 3D 실험은 YBCO의 대표 임계온도 92 K를 사용한 현상 개념 모델입니다. 새 실험은 **전통적인 포논 매개, 등방성 s-wave BCS 원리의 별도 학습 모형**입니다. 92 K를 새 예시의 실제 BCS 임계온도로 쓰거나 YBCO의 쌍 형성을 포논 매개 기작으로 단정하지 않습니다. 두 실험의 온도·조작은 연동하지 않습니다.

포논은 격자 진동의 양자입니다. 지연되는 이온 그림은 직관을 위한 고전적 비유이고, 가상 포논 교환의 점선은 실제 입자 궤적이나 고무줄이 아닙니다. 유효 인력은 특정 에너지·운동량 영역의 성분으로 차폐된 쿨롱 반발과 경쟁합니다. 쌍 구름은 실제 계산한 확률밀도가 아니며, 쌍 형성 확률을 출력하지 않습니다.

쌍 형성과 Ψ(r) = |Ψ(r)| exp(iφ(r))의 거시적 위상 결맞음은 구분합니다. 위상 화살표는 전자나 쌍의 이동 방향이 아닙니다. 같은 방향은 정지 평형의 단순화이고, 초전류에는 위상 기울기와 벡터 퍼텐셜이 함께 관계합니다. 국소 위상 도해는 A = 0인 열린 구간을 가정하며 닫힌 고리의 플럭소이드 양자화를 계산하지 않습니다.

갭 도해는 E_k = √(ξ_k² + |Δ|²)의 **준입자 분산**이며 상태밀도 그래프가 아닙니다. 축은 임의 기준 에너지로 정규화한 모식도이고 실제 단위를 적용하지 않습니다. 2Δ(0) ≈ 3.52 k_B Tc는 균일한 약결합 BCS의 T = 0 근사로, 모든 초전도체에 보편적인 비율이 아닙니다.

위상 변형의 상대 비용은 이웃 영역의 1 − cos(위상차) 평균으로 비교합니다. 실제 위상 강성이나 전류의 측정값이 아니며, 전자기장까지 포함하면 게이지 불변 위상차를 사용해야 합니다. 이 변형 비용을 정상 금속의 줄열 손실과 동일시하지 않습니다. 에너지 갭과 위상 강성은 서로 다른 척도입니다. 쌍 형성만으로 항상 초전도 상태가 보장되는 것은 아닙니다.

직류 저항 0은 적절한 온도·자기장·전류 조건에서 유지되는 집단 양자 성질입니다. 모든 전자가 쌍을 이루거나, 모든 산란과 충돌이 사라지거나, 단단한 쌍이 격자를 뚫고 지나간다는 모델이 아닙니다. 소용돌이 운동과 위상 미끄러짐 등에 의한 손실은 상세 계산하지 않습니다.

### 접근성과 수명주기

처음에는 정지 상태입니다. `prefers-reduced-motion`을 안내하고 사용자가 명시적으로 재생할 때만 애니메이션을 실행합니다. 장면 진행 슬라이더로 정지 상태에서도 관찰할 수 있습니다. 단계 안내만 `aria-live`로 알리고 매 프레임을 읽어주지 않습니다.

새 애니메이션은 약 24 fps 이하로 갱신하며 다른 학습 탭이나 화면 밖에서는 멈춥니다. 문서가 숨겨지면 SVG 작업과 장면 시간 누적을 건너뛰고, 브라우저의 백그라운드 rAF 정지도 활용합니다. 새 조작 이벤트는 Cooper Pair Lab 안에만 등록하고 중복 초기화를 방지합니다. 기존 `app.js`는 원래 `.controls` 입력만 다루도록 세 선택자만 좁혔으며 기존 계산·3D 장면 함수는 그대로입니다.

검증 범위와 한계는 [COOPER-VALIDATION.md](COOPER-VALIDATION.md)를 참고하세요.
