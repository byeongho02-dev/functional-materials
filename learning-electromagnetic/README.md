# 전자기파와 기능성 재료

Materials Learning의 **나노전자재료 및 전자파 차폐** 테마에서 여는 학습자료입니다.

- `index.html`: 한국어 설명, 슬라이더, 3개 학습 탭과 확인 문제
- `styles.css`: 다크 테마와 모바일 레이아웃
- `app.js`: 탭, 학습용 계산, Three.js 장면
- `vendor/three.min.js`: Three.js 0.160.1, MIT 라이선스는 `vendor/THREE-LICENSE.txt`

별도 빌드나 CDN 없이 GitHub Pages에서 실행합니다. 홈페이지의 ALE 시뮬레이터와 기존 학습자료는 각각의 경로를 유지합니다.

## 모델 범위

차폐는 지정한 반사율과 표피 깊이에 따른 단일 통과 근사입니다. 초전도체는 92 K를 경계로 한 이상화된 상태와 저항을 표현하며 자기장·힘·이력을 계산하지 않습니다. 메타표면은 정면 입사와 같은 매질에서 이상적 위상 구배에 따른 조향각을 계산합니다. 실제 측정값이나 설계 예측값이 아닙니다. 각 탭의 가정과 참고자료를 함께 읽어주세요.

## 수정 후 확인

```sh
node --check learning-electromagnetic/app.js
```

홈페이지 → Materials Learning → 나노전자재료 및 전자파 차폐 → 학습자료 진입, 세 탭의 슬라이더·기본값·확인 문제, 학습 테마로 돌아가기를 확인합니다. WebGL을 사용할 수 없는 경우 2D 대체 보기와 계산 기능을 사용합니다.
