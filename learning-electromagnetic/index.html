표면 반사율은 그대로 두고, 두께를 늘려보세요. 투과가 줄어든 만큼 어떤 비율이 커지나요?

THE IDEA

반사와 흡수는 서로 다른 경로

반사는 파가 표면에서 되돌아가는 것, 흡수는 재료 내부에서 전자파 에너지가 열 등으로 바뀌는 것입니다. 투과는 반대편으로 빠져나간 에너지입니다.

도체 안의 전기장 진폭은 표피 깊이 δ만큼 진행할 때 약 1/e로 줄어듭니다. 주파수가 높아지면 δ가 작아져, 같은 두께에서도 흡수가 더 커집니다.

READ THE MODEL

무엇을 계산하고 있을까?

δ = √[1 / (π f μ₀ σ)]
T = (1 − R) e−2t/δ   A = 1 − R − T
SE = −10 log₁₀(T)

σ = 1.0 × 10⁶ S/m, μᵣ = 1인 도체의 단일 통과 근사입니다. R은 비교를 위한 독립 입력이며 실제로는 재료·주파수·두께에 따라 달라집니다. 경계면의 다중 반사는 생략했습니다.

THE IDEA

저항 0과 자기장 배제

임계온도 아래에서는 전기저항이 0이 되는 초전도 상태가 가능합니다. 초전도체가 충분히 약한 자기장을 내부에서 밀어내는 현상이 마이스너 효과입니다.

제2종 초전도체의 혼합상(Hc1 < H < Hc2)에서는 자속이 소용돌이 형태로 일부 침투합니다. 이 자속이 결함 등에 붙잡히는 것이 자속 고정이며, 안정적인 부상에 기여할 수 있습니다.

READ THE MODEL

온도와 저항의 관계

T < Tc에서 0, 그 이상에서는 완만히 증가하는 이상화된 정규화 저항입니다. 실제 저항 단위 Ω를 계산한 그래프가 아닙니다.

모델의 범위

온도만으로 상태를 전환하는 개념 모델입니다. 임계자기장·임계전류·이력·힘의 평형은 계산하지 않습니다. 혼합상 그림은 적절한 외부장이 있다고 가정합니다. 실제 전이 폭과 저항값은 시료마다 다릅니다.

03 / STEER THE WAVE

얇은 표면으로 빛의 방향을 바꾸다

파장 · 주기 · 위상 구배

3D 개념 모델
인접한 기둥마다 위상차 → 기울어진 투과 파면기둥의 높이·색은 위상만을 개념적으로 표현합니다.
입사 파면투과 파면위상 지연드래그로 회전 · 휠로 확대

실험 조건

정면 입사에 대한 투과 조향각 θ
+19.5°
sin θ = λ Δφ / (360° p)
0.333

오른쪽으로 기울어진 파면을 관찰합니다.

해볼 실험

위상차를 0°로 맞추고 부호를 반대로 바꿔보세요. 파면은 어느 쪽으로 기울어지나요?

THE IDEA

작은 지연을 모아, 새로운 파면으로

메타표면은 파장보다 작은 구조를 배열해 빛의 위상 등을 조절하는 얇은 표면입니다. 각 구조가 파를 조금씩 다르게 지연시키면, 통과한 파들이 모여 기울어진 파면을 만듭니다.

위상차가 0이면 정면으로 진행합니다. 위상 구배의 부호를 바꾸면 조향 방향도 반대가 됩니다. 화면의 기둥 높이만으로 실제 광학 특성을 예측할 수는 없습니다.

READ THE MODEL

위상 구배와 조향각

sin θ = (λ / 2π) · (Δφ / p)
Δφ의 단위: rad   ·   정면 입사, 같은 매질

일반화된 굴절 관계를 이상적인 위상 구배에 적용한 모델입니다. 이산 배열의 다른 회절 차수, 효율, 편광, 재료 분산은 생략했습니다. |sin θ| > 1이면 이 식이 지정하는 방향의 전파 해가 없다는 뜻이며, 빛이 전부 사라진다는 뜻은 아닙니다.
