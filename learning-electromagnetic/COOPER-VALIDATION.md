# Cooper Pair Lab 검증 결과

## 변경 파일

- `learning-electromagnetic/index.html`: 기존 초전도체 3D 실험 아래에 7단계 실험 및 범위 구분·참고자료 추가, 기존 쿠퍼쌍 details 확장
- `learning-electromagnetic/cooper-pair.js`: 정적 SVG 애니메이션, 단계 설명, 재생·위상·갭·조건 조작 및 독립 정성 모델
- `learning-electromagnetic/styles.css`: 기존 변수와 디자인을 사용하는 CP 전용 스타일, 좁은 화면에서 세로 배치
- `learning-electromagnetic/app.js`: 새 조작을 원래 시뮬레이터 입력에서 제외하는 세 선택자만 수정
- `learning-electromagnetic/README.md`: 사용법, 모델의 과학적 범위, YBCO 구분, 실행·검증 명령
- `tests/cooper-pair.test.cjs`: 외부 의존성이 없는 Node 단위 테스트

## 통과한 검사

```sh
node --check learning-electromagnetic/app.js
node --check learning-electromagnetic/cooper-pair.js
node --test tests/cooper-pair.test.cjs
```

7개 단위 테스트가 통과했습니다. 갭 분산의 대칭성·최소 들뜸·갭 없는 극한, 위상 비용의 전역 위상 및 게이지 불변성, 매끄러운 위상 기울기의 비용, 이온의 지연 반응, 7단계 순서, 재생 종료·재시작·일시정지·속도·격자 재생, 갭·위상·임계 조건의 독립성을 점검합니다.

추가 DOM 통합 검사에서는 264/390/640px를 가정한 SVG 컨테이너 각각에서 7개 장면이 서로 다른 그래픽을 만들고 유한 좌표를 유지하는지 확인했습니다. 총 701개의 DOM·좌표·참조 단언을 통과했습니다. 이는 701개의 서로 다른 브라우저 사용 사례나 실제 화면 검증을 뜻하지 않습니다.

## 검증하지 못한 범위

현재 실행 환경에 브라우저 제어 도구가 제공되지 않아 실제 데스크톱·모바일 브라우저의 시각적 배치, WebGL 렌더링, 화면 낭독기의 실제 발화, 스크린샷은 확인하지 못했습니다. DOM 검사에서 폭을 설정한 것은 실제 브라우저 뷰포트 테스트를 대체하지 않습니다. 스크린샷을 임의로 만들지 않았습니다.

게시 전 실제 화면에서 초전도체 탭을 열어 7단계, 자동재생과 정지, 3D 시점·온도·자속 고정, EMI/메타표면 탭 왕복을 확인할 수 있습니다.

## 모형의 한계

격자·상호작용·쌍 구름·위상·갭과 전류는 원리를 구분하기 위한 정성적 시각화입니다. 문헌의 실측 데이터, 전자쌍 확률, 실제 이온 변위, Tc, 실제 단위의 Δ·위상 강성·전류를 출력하지 않습니다. 전통적 포논 매개 BCS와 YBCO의 쌍 형성 기작을 동일시하지 않습니다.
