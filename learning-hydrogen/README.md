## 파일과 조작

- `index.html`: 8개 주제, 모형·설명·컨트롤, PCT·비교·참고자료.
- `content.js`: 비유·정의·인과 설명·한 문장 정리·출처와 자료 구분.
- `model.js`: 원자 경로, 정성 압력/온도·PCT 관계, 상태 전이. Node에서도 실행합니다.
- `app.js`: Three.js 인스턴스 렌더링, 동일 데이터의 SVG 대체, 이벤트와 수명 관리.
- `styles.css`: MOF·전자기 자료와 같은 네이비·시안 학습 배치. 공통 토큰은 `../assets/learning-common.css`.

단계 이전/다음·바로가기, 재생/일시정지·초기화, 0.5/1/2배 속도, 진행률, 드래그 회전·확대·시점 전환을 제공합니다. 구조에 초점을 두면 방향키로 회전, +/−로 확대·축소, Home으로 시점 초기화, Space로 재생·정지합니다. 모델 바로 아래에도 재생 버튼이 있어 모바일에서 그림을 보며 조작할 수 있습니다.

압력·온도 화면의 입력은 반응에 유리한 방향으로 모식도를 이동시킵니다. 단계 바로가기는 해당 과정의 끝 상태를 보이며, 압력/온도 화면에서 방출 단계를 선택하면 압력을 기준선 아래로, 흡수 단계를 선택하면 위로 맞춥니다. PCT의 조성은 그림을 비교하는 상대 지수입니다. 모든 입력은 실제 실험값이나 반응 속도 예측이 아닙니다.

초기 자동재생이 없습니다. 동작 줄이기 설정에서는 카메라 전환과 조건 입력의 자동 움직임을 생략하고 끝 상태를 즉시 표시합니다. 사용자가 명시적으로 선택한 과정 재생과 수동 단계 조작은 가능합니다. 숨긴 페이지·화면 밖의 모형은 렌더 루프를 중단하고, 복귀 시 경과 시간을 한꺼번에 진행하지 않습니다. WebGL 실패·컨텍스트 손실 시 같은 입자 데이터로 SVG 투영을 그립니다. 중복 초기화는 이벤트를 중복 연결하지 않습니다.

## 과학 모형의 범위

미배포 검토본에서는 압축 수소와 액체 수소를 선택하면 금속 격자 대신 H₂ 분자가 든 용기를 표시합니다. 액체 수소에는 단열 외벽과 아래쪽 액체 영역을 구분했습니다. 같은 H₂ 6분자를 사용하며 분포·크기·벽 두께로 실제 밀도·탱크 압력·저장 용량을 산출하지 않습니다. 수소화물 장면에서만 금속 27개와 H 12개의 격자 경로를 사용합니다.

주황 테두리로 원래 한 분자의 두 H를 추적할 수 있습니다. 8단원의 불순물 조작은 한 해리 자리를 막아 그 H₂가 밖에서 기다리는 비교를 시작합니다. 조건을 바꾸면 실험을 처음부터 준비합니다. 10/12는 대표 입자의 그림이며 실제 용량 감소율·피독률이 아닙니다. 합금 선택은 여전히 공통 격자 모식도를 사용합니다. 방출·흡수와 PCT 경로를 일치시켰으며 압축/액체 재생은 해당 상태의 분자 움직임을 유지합니다.

- 금속 원자 27개와 H 원자 12개의 ID를 유지합니다. H₂의 H–H 연결은 격자 밖에서만 표시하며, H가 내부에 들어간 뒤에는 분자 결합선을 만들지 않습니다. 방출은 동일 경로를 거꾸로 따라 표면에서 재결합하는 방식입니다.
- 좌표·원자 크기·단순 입방 안내선은 실제 합금의 CIF나 금속 결합을 재현하지 않습니다. TiFe·LaNi₅·Mg₂Ni를 선택해도 실제 합금별 결정구조로 바뀌는 것은 아닙니다. 보라색과 점선은 수소화물 영역·M–H 상호작용의 개념 기호입니다.
- 일정한 초 단위 재생 시간은 학습 속도입니다. 확산계수·활성화 에너지·반응 속도·저장 용량을 계산하지 않습니다. 균열·표면 차단도 실제 사이클 수·열화율로 환산하지 않습니다.
- `P_eq = exp[1.8 (1−1/T_rel)]`는 전형적인 온도 경향만 표현하는 **임의 무차원 교육 함수**입니다. 1.8은 실제 합금의 열역학 계수가 아닙니다. 압력 비교는 두 상 공존 구간의 기준선에 대한 정성적 판단이며 실제 조성·이력 문턱·속도를 모두 재현하지 않습니다.
- PCT의 경계 0.22/0.78, 작은 평탄부 기울기, 경로 간격 ±0.17도 교육용 가정입니다. 축은 Relative/a.u.이며 상대 압력 축은 로그입니다. 곡선은 실측 파일을 피팅한 결과가 아닙니다.
- van’t Hoff는 탈수소화 엔탈피·엔트로피를 H₂ 1 mol당 정의하고, T는 K, 로그 안의 압력은 기준 압력과의 비로 설명합니다. 화면의 상대 온도를 물리식의 실제 T로 쓰지 않습니다.
- PCT 조성에 따른 색·입자 배치는 두 상의 비율을 직관적으로 비교하는 표시입니다. 고정된 소수의 입자를 세어 실제 MHₓ 조성이나 wt%·L/kg를 산출하지 않습니다.
- 일반적인 연료전지차의 고압 기체 저장과 수소화물 탱크를 구분합니다. 금속수소화물은 절대적 무위험 저장을 뜻하지 않습니다. 무게·부피 기준, 열교환기·용기 포함 시스템 기준을 구분합니다.

## 참고자료 확인

DOE의 Materials-Based / Sorbent / Physical Hydrogen Storage 본문을 확인해 재료/시스템 기준과 저장 상태를 구분했습니다. Klopčič 등(2023, DOI 10.1016/j.est.2023.108456)은 저자 소속 대학의 서지·초록을 확인했고 발행사 원문은 접근 제한으로 전체 대조하지 못했습니다. 2021년 Frontiers 검토 논문(DOI 10.3389/fenrg.2021.616115)에서 PCT·van’t Hoff·활성화·반복 및 열관리 관련 설명을 확인했습니다. 수치 표·그림은 가져오지 않았습니다. 페이지 하단과 `content.js`에 직접 링크를 연결합니다.
