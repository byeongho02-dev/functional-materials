## 값·식·가정

- **SI 정의:** N_A=6.02214076×10²³ mol⁻¹, N=nN_A. 대상은 선택 원소의 중성 원자이며 H₂/O₂/Cl₂ 분자가 아닙니다. 그림은 대표 입자이며 1mol 전체가 아닙니다.
- **질량:** m=nM. CIAAW의 H1.008/C12.01/O16.00/Na22.99/Cl35.45/Si28.09 g/mol은 교육용 반올림 평균입니다. 핵의 H-1/C-12/O-16/Na-23/Cl-35/Si-28 질량수와 다릅니다. Cl-35의 중성자는18개입니다.
- **원자/결합:** 크기·거리·Bohr 선은 설명 기호입니다. NaCl의4³ 자리에는32Na⁺/32Cl⁻, 내부 최근접 이웃6개입니다. CH₄ 방향은 사면체 cosθ=−1/3입니다. CNT128C는 내부3이웃/끝2이웃 벌집 연결을 말린 모형으로 지름 조작이 실제 nm·합성·밴드 계산은 아닙니다.
- **센서 임의 함수:** t∈[0,1]에서 R_NTC=exp(−2t), R_PTC=1+2t. 2는 실제 재료 계수가 아닙니다. 가스 u∈[0,3]에서는 R=1+1.5u(u<1), 2.5(1≤u<2), 2.5−1.5(u−2)(2≤u≤3)를 장면·곡선·커서에 공통 사용합니다. 2CO+O₂→2CO₂의2C/4O를 보존하고 위치를 연속 연결합니다. 실제 산소 종·전하·반응속도는 단정하지 않습니다.
- **광접합:** 내장 전기장 n→p, 전자 n쪽·정공 p쪽, 외부 광전류 기여 p→n를 구분합니다. 실제 선의 개방 간격으로 광전압과 외부 전류를 구분합니다. 상대 공핍층/밴드0.3·0.8·1.4는 실제 전압·도핑·공핍폭·전류 해가 아닙니다. 순방향 총 전류를 광전류 기여만으로 계산하지 않습니다.
- **병렬 부재:** k=EA/L, Fᵢ=F_total kᵢ/Σk, δ=F_total/Σk. E_b=10GPa(임의교육입력), A_b=100mm², A_i=25mm², L=100mm, F=100N, GPa×1000=N/mm². 완전 결합·공통 축변위·선형 탄성 가정입니다. 변위는 장면 길이로 환산해1000배 확대합니다. 생체 형상·재형성·FEA가 아닙니다.
- **PDF 사례값:** 2강p33의58/161GPa는 TNTZ/SUS316L의 토끼 경골 고정 nail·이식24주 X선 맥락입니다. p34는 결정방위 의존 E이며 보편 고정값의 근거가 아닙니다. 시험법 보강은 Niinomi & Nakai의3점굽힘 관련 검색 인덱스 확인 범위입니다.
- **인장:** 입력 E20~200GPa, ε0~.002, L₀100mm, A₀10mm², ν.3. σ=Eε, F=σA₀, ΔL=εL₀, A≈A₀(1−νε)². 축/횡 변형80배 확대입니다. 실제 항복 여부·진응력·파괴값을 예측하지 않습니다. 연성/취성은 별도 정성 경로이며 커서는 곡선 위에서 보간합니다.
- **기공:** 같은 부피216복셀 중 round(216P/100)를 제거합니다. 목표40%의 구현은39.8%입니다. 절개는 보기만 바꾸고 원래 외곽 기준 기공률을 유지합니다. 강성/강도 곡선은 임의 방향도이며 성능값·보편 지수 법칙을 산출하지 않습니다. p41 약30%는 특정 소결체 사례이고 옆0.2% offset stress는 인장강도와 다릅니다.
- **NiTi 구조:** Ni/Ti 자리·ID를 유지합니다. B2는 꼭짓점8×1/8과 중심1의 다른 원자종을 갖습니다. B19′는 단사정 구조를 설명하는 자체 전단 모형이며 검증 Wyckoff/CIF 좌표가 아닙니다.
- **상태 이력:** M_f=.25/M_s=.45/A_s=.55/A_f=.75는 임의 정규화 위치입니다. 부분 가열/냉각 이력을 보존하고 현재 하중·온도 범위를 함께 판단합니다. 하중 변태의 .3/.75·.12/.5 경로도 임의 상대 가정입니다. 열·응력·미세구조의 전범위 연성 해석이 아닙니다.
- **일방향/구속:** 무하중 완전 역변태 후 variant 변형 이력을 지워 냉각만으로 다시 휘는 two-way 오개념을 막습니다. 편향 없는 액추에이터의 위치 이력은 별도로 보존합니다. 구속을 켤 때 현재 위치를 저장해 유지하고 상 상태는 바뀝니다. 회복 응력·속도·수명값을 만들지 않습니다.
