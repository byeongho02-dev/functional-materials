# 6개 테마·4강 통합 검증

## 구현 범위

메인은 `fundamentals → biomaterials → sma → hydrogen → nano → mof` 순서의 6개 학습 테마입니다. 항균·나노촉매의 별도 카드/라우팅 항목을 제거했고 기존 강의 내용과 파일은 보존합니다. 4강 카드와 기존 `#theme-hydrogen` 주소는 실제 학습 페이지로 연결됩니다. ALE는 별도 메뉴와 기존 URL을 유지합니다.

새 4강은 8개 주제, 보존되는 H 원자 12개의 5단계 과정, 상대 압력/온도, 정성 PCT·이력, 합금·저장 방식·응용 비교와 반복 영향 조작을 제공합니다. [모형·출처·자료 범위](../../learning-hydrogen/README.md)를 확인하세요.

공통 CSS는 명시적으로 선택한 학습 페이지와 메인에만 로드합니다. 기존 1~3강의 인라인 학습 스크립트와 ALE 코드/게시 파일은 바꾸지 않았습니다. 원래 과학 그림은 밝은 배경·진한 글자, 설명 패널은 네이비·밝은 글자를 사용합니다.

## 원본과 과학적 검증의 한계

- `기능성재료 4강.pdf`는 제공되지 않아 직접 대조하지 못했습니다. 첨부 작업지시서가 허용한 페이지별 개요로 강의 범위를 구성했습니다.
- DOE 3개 저장 자료의 본문, 2021년 Frontiers 검토 논문의 관련 내용을 확인했습니다. 2023년 논문은 저자 소속 대학의 서지·초록을 확인했고 발행사 전체 원문은 접근 제한이 있었습니다.
- 원자 좌표·경로·압력/온도 함수·PCT의 경계와 이력은 교육용입니다. 실측 구조/성능·동역학·사이클 수명을 예측하지 않습니다. 출처 미확인 L/kg·제품/차량 성능은 추가하지 않았습니다.
- 기존 2강의 외부 Wikimedia 사진 링크는 유지합니다. 새 4강과 공통 디자인에는 외부 이미지·폰트·CDN을 추가하지 않았습니다.
- 실제 비전공자 학습 효과 연구, 모든 브라우저/보조공학 조합과 실제 모바일 기기의 터치 감각은 별도 평가가 필요합니다.

## 실행 명령

```sh
npm ci
node --check learning-hydrogen/model.js
node --check learning-hydrogen/content.js
node --check learning-hydrogen/app.js
npm run test:learning:model
npm run test:fab:model
npm run build:fab
npm run build:fab:static
node --test tests/pages/static.test.cjs
npm run test:pages
```

별도 린트 명령은 저장소에 정의되지 않았습니다. Node의 모델 검사는 의존성 없이 실행합니다. 선택적 Linkedom DOM 검사는 개발 환경의 `NODE_PATH`를 사용할 때 수행하며 배포 의존성이 아닙니다. 로컬 환경의 npm 캐시 권한 문제는 작업 폴더의 캐시를 지정해 해결했습니다.

이 관리 환경에는 지원되는 로컬 브라우저 제어 도구가 없어 기존 GitHub Actions의 실제 Chromium/Playwright를 사용합니다. 새 로컬 미리보기 서버나 브라우저 설치로 우회하지 않습니다. 최종 실행 결과와 커밋별 로그는 PR의 Checks와 작업 결과 보고에 연결합니다.

## 검사 내용

- 수소 12개·금속 27개와 수소 ID 보존, 유한한 좌표, 격자 내부에 H₂ 연결이 없는지, 단계 경계에서 연속 경로인지.
- 흡수/방출·고온 고압의 반례·평형 부근, 온도에 따른 PCT 이동, 연속적인 평탄부와 이력 토글, α/β 영역 표시.
- 재생 종료·일시정지·초기화·중복 초기화, 숨긴 문서·화면 밖에서 루프 중단, 동작 줄이기, SVG 대체 및 실제 Three.js 수학 경로.
- 홈페이지 정확한 6개 테마 순서·번호·삭제된 테마의 일반 목록 복귀·4강 직접 진입·홈/뒤로가기/새로고침.
- 1440/1280/768/390/360 px에서 4강 8개 주제, 버튼 44 px·텍스트 잘림·가로 넘침, 회전·확대·단계·진행률·압력/온도·PCT·합금·응용·반복 영향·JavaScript 오류.
- 같은 5개 너비에서 1~3강 전체 단원 이동과 주요 입력, EMI 3개 탭/슬라이더, MOF 원자 확대, ALE 실제 WebGL 챔버와 절개 동작.
- 기존 MOF의 9개 주제·하위 장면·열 높이·SVG 대체, 기존 ALE 전체 모델/카메라/입자·프로세스/모바일 회귀.
- 정적 게시 파일과 소스의 일치, 기존 1~3강 인라인 스크립트 동일성, 수정 HTML의 상대경로.

새 화면 증거는 Actions의 `learning-integration-evidence`, 기존 ALE/MOF 증거는 `icp-preview-test-evidence` 아티팩트에서 확인합니다. 스크린샷은 측정 데이터나 논문 그림이 아니라 실제 브라우저의 실행 결과입니다.
