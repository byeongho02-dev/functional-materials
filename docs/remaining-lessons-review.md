## 과학적 범위

가정·단위·비유의 한계를 조작 근처에 둡니다. 실제 합금 구조·저장 성능, MOF 흡착 속도, 메타표면 효율, BCS 실제 Δ/Tc를 임의 입력으로 예측하지 않습니다. 전통적 BCS와 구리산화물 YBCO를 구분합니다. 4강 PDF 원본 미확인 안내와 기존 학술 링크를 유지합니다. 라이브러리·CDN·빌드 의존성을 추가하지 않고 로컬 Three.js 0.160.1/MIT와 자체 SVG를 사용합니다.

## 검토할 흐름

- 수소저장: 저장 상태 3가지 → 같은 H 추적 → 불순물 자리 차단.
- MOF: 마디/링커 확대 → 흡착의 크기 비교 → 마지막 교환 장면.
- EMI: 입사·반사 → 재료 내부 → 전체 에너지, 같은 조건에서 두께 변경.
- 메타표면: 지역 위상 → 파의 합에서 관찰각 변경 → 예측 방향 맞추기.
- 초전도: YBCO와 별도 모형의 경계 문구 → 7단계 → 결맞음/무질서 → 갭/비틀기.
